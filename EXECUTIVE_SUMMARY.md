# VETTED: Executive Summary

## 🌍 Vision

**Build the Stripe/Rails of Cross-Border Technical Hiring**

VETTED is a global trust infrastructure platform that eliminates friction in high-value offshore technical hiring by combining biometric identity verification, automated skill assessment, and programmatic milestone payments into a single, seamless protocol.

---

## 🎯 The Problem

### **Current State: Broken Trust Infrastructure**

Western enterprises face three critical barriers when hiring offshore technical talent:

**1. Identity Fraud Risk ($10B+ annual loss)**
```
Resume fraud rate: 40%+
Portfolio plagiarism: 30%+
Interview impersonation: 15%+
Post-hire identity mismatch: 5%+

Result: Companies waste $50k-$100k per bad hire
```

**2. Payment Fraud Risk ($5B+ annual loss)**
```
Escrow scams: 25% of cross-border transactions
Milestone disputes: 40% of contracts
Payment delays: 60-90 days average
Compliance overhead: 40+ hours per contractor

Result: Companies lose capital + opportunity cost
```

**3. Tax Compliance Nightmare ($2B+ annual fines)**
```
Missing W-8BEN forms: 70% of foreign contractors
IRS withholding penalties: $25k+ per incident
Audit failures: 35% of companies
HR overhead: 15+ hours per form

Result: Legal risk + massive compliance cost
```

### **Total Addressable Problem:**
```
Market inefficiency: $17B+ annually
Affected contracts: 2M+ per year
Affected companies: 100k+ per year
Affected talent: 5M+ globally
```

**Automated 3-Tier Gauntlet:**

**Tier 1: Portfolio Audit (5 minutes)**
```
✓ GitHub commit history analysis
✓ Code complexity scoring
✓ Authorship verification
✓ Plagiarism detection
✓ AI-generated code detection

Output: Portfolio authenticity score (0-100)
Pass threshold: 85+
```

**Tier 2: Sandboxed Code Lab (60 minutes)**
```
✓ Real debugging challenge
✓ Unit test suite execution
✓ Keystroke pattern analysis
✓ Execution speed tracking
✓ Third-party tool detection

Output: Technical skill score (0-100)
Pass threshold: 85+
```

**Tier 3: AI Technical Viva (15 minutes)**
```
✓ Dynamic GPT-4 questions about Tier 2 code
✓ Live camera biometric tracking
✓ Voice pattern analysis
✓ Eye contact monitoring
✓ Multiple face detection
✓ Third-party assistance detection

Output: Live integrity score (0-100)
Pass threshold: 95+
```

**Final Output:**
```
VettedME Passport (Un-fakeable Digital Credential)
├── Biometric hash (Smile ID government verification)
├── Skill scores (Tier 1, 2, 3)
├── GitHub profile
├── Contract history
├── Performance rating
└── Cryptographic verification link

Shareable URL: vettedme.com/passport/{id}
LinkedIn-ready, employer-trusted
```

**Automated Capital Lock:**
```

Status tracking:
├── AWAITING_TRANSFER (0-3 days)
├── CAPITAL_CONFIRMED (webhook triggered)
├── ESCROW_LOCKED (ready for work)
└── CONTRACT_ACTIVE
```

---

### **Step 4: Work Delivery & Release**

**Biometric Handshake Protocol:**
```
1. Contractor completes milestone
2. Contractor submits work + requests release
3. Enterprise reviews work
4. Enterprise approves release
5. ⚡ CRITICAL: Contractor performs live biometric scan
6. System verifies:
   ✓ Face match (95%+ confidence vs passport baseline)
   ✓ Liveness detection (no video replay, no photos)
   ✓ W-8BEN tax form signed
   ✓ No fraud flags
7. If verified → Airwallex payout triggered (instant)
8. If failed → Passport revoked + wallet frozen + alert
```

**Payment Breakdown:**
```
Milestone Value:               $10,000 USD
Platform Fee (15%):            -$1,500 USD
FX Spread (0.5%):              -$50 USD
─────────────────────────────────────────
Net Contractor Payout:         $8,450 USD

Platform Revenue:              $1,550 USD
Contractor Receives (in NGN):  ₦13,520,000 (~$8,450)

Settlement Time: 24-48 hours (vs 60-90 days traditional)
```

### **Step 5: Tax Compliance (Automated)**

**W-8BEN Generation (< 5 seconds):**
```
System pulls from KYC data:
├── Full legal name (from NIN)
├── Date of birth (from BVN)
├── Citizenship (Nigeria)
├── Permanent address (from verification)
├── Foreign tax ID (NIN/BVN)

→ Auto-fills IRS Form W-8BEN

→ Stores in encrypted vault
→ Provides instant download link

Enterprise benefit:
✓ Zero HR overhead (vs 15+ hours manual)
✓ 100% IRS compliant
✓ Instant audit-ready documentation
✓ No withholding penalties
```
