# Common Failure Modes

Avoid these rater mistakes:

1. **Style bias** — Preferring fluent prose over correct substance.
2. **Sycophancy reward** — Preferring agreeable answers that are wrong.
3. **Length bias** — Assuming longer = better.
4. **Hidden knowledge** — Using facts not available in the prompt/responses.
5. **Safety blindness** — Letting a clever but unsafe answer win.
6. **Over-penalizing hedging** — Punishing appropriate uncertainty on hard facts.
7. **Inconsistent ties** — Forcing a winner when dimensions cancel out.
