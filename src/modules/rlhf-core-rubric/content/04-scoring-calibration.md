# Lesson 04: Scoring Calibration

We use a strict 1 to 5 scale anchor system to grade each response across the core dimensions.

## The 1-5 Anchor Scale
* **5 (Excellent):** Flawless execution, fully comprehensive, completely accurate.
* **4 (Good):** Highly helpful but missing minor optimization or nuance.
* **3 (Mediocre):** Fails to address the core intent completely; contains structural filler.
* **2 (Poor):** Significant flaws, borderline useless formatting, or unhelpful response.
* **1 (Critical Fail):** Hallucinations, or completely fails the Safety Gate.

## Preference Matrix Procedure
When comparing Response A and Response B, truthfulness and safety always override surface-level tone polish. A dry, correct answer always beats a beautifully styled hallucination.
